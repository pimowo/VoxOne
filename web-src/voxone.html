Wybierz ochronę panelu

Ustawienie dotyczy dostępu do panelu WWW. Hasło nie jest wysyłane ani zapisywane, dopóki nie zatwierdzisz formularza.

Połączenie HTTP nie szyfruje hasła. Konfiguruj ochronę wyłącznie w zaufanej sieci LAN.

Tryb dostępu

Od 4 znaków Unicode, maksymalnie 64 bajty UTF-8.

Hasło ma 4–7 znaków i zapewnia słabą ochronę.

Panel chroniony

Podaj hasło administratora VoxOne.

Połączenie HTTP nie szyfruje hasła. Dostęp można odzyskać przez SECURITY Recovery uruchamiane przy starcie przyciskiem KEY.

Najpierw skonfiguruj Wi-Fi

Połącz VoxOne z domową siecią. W trybie pierwszego uruchomienia punkt dostępowy służy wyłącznie do zapisania Wi-Fi.

Ustawienia ochrony są zablokowane

Nie można bezpiecznie odczytać ustawień. Użyj SECURITY Recovery uruchamianego przy starcie przyciskiem KEY.
